# challenge-devops-001
## incrementN DevOps Assignment

This repo has a small app and a GitHub Actions pipeline with several things wrong with it — some cause hard failures, some fail silently (the pipeline "succeeds" but doesn't actually do what it should).

## Your Task

- Fork this repo in your GitHub account
- Leave the `main` branch as is. Create a new branch from `main` where you will make changes
- Make the CI pipeline trigger on raising new PRs to `main` branch only
- Get the pipeline fully green, and make sure it's actually doing what a correct pipeline should do (not just "not erroring")
- Implement any best practices and standards as you would do if this was a regular task at work
- Raise a PR to `main` 
- Test the pipeline as many times needed, push fixes into the same branch, until all looks good
- Write a short `RCA.md` covering what was wrong, what you changed, why - commit this into the branch as well
- Send back your PR link.

AI tools are fine to use. But make sure you understand what code changes you made and why. You are responsible for every change you introduce in a PR. So you should be able to explain each change clearly and confidently.
